## 🕹️ Tic-Tac-Toe Game

This is a simple web-based **Tic-Tac-Toe** game built using **HTML, CSS, and JavaScript**. The game features a clean UI and allows two players to play in turns. It includes win detection for all possible win conditions and a reset button to restart the game.

### 🎯 Features

* Playable 3x3 Tic-Tac-Toe grid
* Turn-based gameplay for Player X and Player O
* Automatic win detection (rows, columns, diagonals)
* Draw detection when all boxes are filled with no winner
* Reset functionality to restart the game

### 🚀 How to Clone and Use This Repository

Follow the steps below to clone and run the Tic-Tac-Toe game on your local machine:

#### 🔧 Prerequisites

* A modern web browser (e.g., Chrome, Firefox, Edge)
* Git installed on your system (optional for cloning via command line)

#### 📥 Clone the Repository

```bash
git clone https://github.com/your-username/your-repo-name.git
```

Or download the ZIP:

* Click the green **Code** button at the top of the repo
* Select **Download ZIP**
* Extract the ZIP file on your computer

#### 🚀 Run the Game

1. Open the project folder.
2. Locate the `index.html` file.
3. **Double-click** the file or **right-click → Open with → Your browser**.
4. Start playing the game by clicking the grid boxes.

#### 🔄 Resetting the Game

Click the **Reset** button to clear the board and start a new round.
